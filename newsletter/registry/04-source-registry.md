## 2. Enforcement Architecture in the Guardrail Pipeline

1. **Automated Pre-Flight Registry Check (`newsletter/bin/run-pipeline.js`):** Every candidate item ingested by the pipeline must reference a valid `source_id` present in `newsletter/registry/sources.json`.
2. **Hard License Gate:** If a source entry lacks `verified: true`, lacks an `https://` `verification_url`, or has a `license_status` outside `["FREE_TO_USE_PUBLIC_DOMAIN", "FREE_TO_USE_CC", "USE_BY_CITING"]`, the item is **automatically dropped** before draft assembly and written to the review package's `dropped_items` audit array.
3. **Prohibited String Filter:** The pipeline scans all generated Markdown, HTML, and plain text for the forbidden phrase `"reuse terms unverified"` (case-insensitive) and halts with a non-zero exit code if detected.
